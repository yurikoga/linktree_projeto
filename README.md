# 🌳 LinkTree Pessoal

Um projeto de página de links (estilo Linktree) desenvolvido com o objetivo de consolidar conceitos essenciais de desenvolvimento front-end, aplicando uma estrutura semântica e estilização moderna.

O projeto centraliza minhas principais redes profissionais e acadêmicas em um layout limpo, responsivo e focado na experiência do usuário.

---

## 🚀 Tecnologias Utilizadas

O projeto foi construído utilizando as tecnologias web nativas:

* **HTML5:** Estrutura semântica e integrada com fontes externas (Google Fonts - Inter).
* **CSS3 Moderno:** * **Flexbox:** Utilizado para a centralização perfeita do layout no `body` e distribuição dos elementos internos.
    * **Variáveis CSS (Custom Properties):** Centralização da paleta de cores (`--bg`, `--fundo-btn`, etc.), facilitando futuras manutenções ou implementação de temas (como Dark/Light mode).
    * **Nesting (Aninhamento Nativo):** Organização do código utilizando a nova especificação de aninhamento de seletores do CSS, mantendo o arquivo mais limpo e legível.
    * **Pseudo-classes (`:first-child`, `:last-child`, `:hover`):** Estilização cirúrgica de elementos de texto e criação de micro-interações fluidas nos botões.

---

## 🎨 Destaques do Código e Aprendizados

Durante o desenvolvimento deste projeto, fiz questão de aplicar algumas boas práticas de CSS:

* **Efeito Hover Dinâmico:** Implementação de transição suave (`transition: .5s`) combinando `transform` (`translateX` e `translateY`) com `box-shadow` para dar uma sensação de elevação 3D realista quando o usuário passa o mouse sobre os botões.
* **Ajuste Inteligente de Imagem:** Uso da propriedade `object-fit: cover` na foto de perfil para garantir que a imagem mantenha sua proporção original e não fique distorcida ao ser moldada pelo `border-radius: 50%`.
